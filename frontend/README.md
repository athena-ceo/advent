# Adventure frontend

React + Vite + TypeScript UI (added in the imaging/UI phase): a chat interface
that drives the game through the MCP backend, a location image panel with lazy
AI-generated art, and a Mermaid "God's-eye" cave map derived from the parsed
travel table. Container will run on port 3040.
